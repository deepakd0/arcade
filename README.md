## Brick Box 12-in-1

Falling blocks, lane racing, tank duels, snake, frog crossing, brick breaker, shooters and a pattern copy game on a 10x20 dot screen. Speed and level 1-10, hi-scores and beeps.

- **Genre:** Retro handheld
- **Plays on:** Laptop (keyboard), phone (touch, installable, offline)
- **Play:** [Play on laptop](https://deepakd0.github.io/brick-box/laptop.html) · [Play on phone](https://deepakd0.github.io/brick-box/phone.html)
- **Source:** https://github.com/deepakd0/brick-box

## Rotor Storm

Fly, gun, rocket and winch through story missions across a desert warzone, then hold out in endless Last Stand.

- **Genre:** Arcade action
- **Plays on:** Keyboard and mouse, touch, gamepad
- **Play:** [Play](https://snowy-leaf-322.higgsfield.gg/)
- **Source:** private
